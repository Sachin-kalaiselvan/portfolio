Recovering the truth

Independent checks

The model

Weekly revenue = baseline + one term per channel. Baseline is level, trend, yearly seasonality (two sin/cos pairs) and any control columns. Each channel's spend goes through carry-over (geometric adstock, part of this week's effect spills into next week) and saturation (hill curve, double the spend ≠ double the effect), then gets a non-negative weight.

Fitting

For any carry-over + curve shape the weights are solved exactly with non-negative least squares. The shapes themselves get searched with nelder-mead from a few starts. Soft priors keep the shapes sane when the data can't pin them down (carry-over ~0.3, saturation near typical spend, shape ~1.5).

How sure is it

"add 90% ranges" refits on 40 resampled versions of your history (8-week chunks of the residuals so streaks stay intact) and shows the middle 90% of each channel's ROI.

Lift tests

Each experiment becomes one extra observation of that channel's ROI, weighted by how tight the test was. On simulated brands one test on the smallest channel cut its typical ROI error ~3x (see benchmark).

The budget

A channel's weekly response at steady spend = weight × hill(spend). Those curves are S-shaped, so anything that just chases marginal return can get stuck. Instead the budget gets cut into 400 units and split exactly with dynamic programming, then fine-tuned by shuffling money between pairs of channels. Vs scipy SLSQP with 20 starts on 300 random cases it never lost and won about half.

Limits

History shows correlation, only experiments prove cause. Curves are only trustworthy inside the spend range you've actually tried, so by default each channel is capped at 2x its biggest recent week. Change it if you want.
