# Sachin Kalaiselvan — portfolio

A drivable 3D portfolio. It is built on Bruno Simon's open-source [folio-2025](https://github.com/brunosimon/folio-2025), used under the MIT license; see `license.md`. The engine, models, sounds and island are Bruno's work. The projects, experiments, career, links and the SACHIN landing letters are Sachin's.

## Run

```
npm ci --force
npm run dev       # local
npm run build     # production build in dist/
```

## Where Sachin's content lives

- **Projects, lab and links:** `sources/data/projects.js`, `lab.js` and `social.js`.
- **Images:**
  - projects: `static/projects/images/sk-*`
  - lab: `static/lab/images/sk-*`
  - career labels: `static/career/*.png`
- **Landing letters:** generated by `scripts/landing-letters.mjs` into `sources/data/landingLetters.js`, then swapped in by `sources/Game/World/Areas/Areas.js`.
- **Page copy:** title, meta tags, the welcome panel and "Behind the scene" are in `sources/index.html`.
- **Start point:** `?spawn=projects|lab|career|social` chooses where the car starts.
